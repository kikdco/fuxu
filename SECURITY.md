# Security

This repository currently contains a static prototype. It does not include user accounts, a remote API or production personal data storage.

If you find a security issue, do not open a public issue containing personal data or exploit details. Contact the repository owner privately and include:

- affected file or feature
- reproduction steps
- expected and actual behavior
- potential impact

The production version must add authentication, server-side authorization, data export and deletion, and a clear privacy policy before accepting real user records.
